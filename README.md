🌊 IoT-Based Flood Detection System Using ESP32

📌 Project Overview

The IoT-Based Flood Detection System is designed to monitor water levels and identify potential flood conditions using an ESP32 microcontroller and an HC-SR04 ultrasonic sensor.

The system measures water levels continuously and activates an alert when the water reaches predefined warning or danger thresholds.

🎯 Objectives

- Monitor water levels continuously.
- Detect rising water levels.
- Generate alerts during critical conditions.
- Support future remote monitoring using IoT technology.
- Help reduce flood-related risks.

🛠️ Technologies Used

- ESP32 Microcontroller
- Arduino Programming (C/C++)
- HC-SR04 Ultrasonic Sensor
- Internet of Things (IoT)
- Wi-Fi Communication (planned extension)

🔧 Hardware Components

- ESP32 Development Board
- HC-SR04 Ultrasonic Sensor
- Buzzer
- Resistors
- Breadboard
- Jumper Wires
- USB Cable

⚙️ Working Principle

1. The ultrasonic sensor measures the distance to the water surface.
2. ESP32 receives the sensor readings.
3. The water level is calculated.
4. The readings are compared with predefined thresholds.
5. The buzzer activates when warning or danger conditions occur.

✨ Key Features

- Continuous water-level monitoring.
- Normal, warning and danger level detection.
- Audible alerts using a buzzer.
- Expandable Wi-Fi-based remote monitoring.
